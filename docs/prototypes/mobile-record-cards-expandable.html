Collapsed secondary details

This pattern treats each record as a scanning unit first. Users see the date, title, amount, and a small set of summary facts, then expand only when they need the longer note or secondary fields.

  • Best for long lists and repeated daily scanning.
  • Keeps rows short while still allowing full detail access.
  • Adds one more interaction and hides some information by default.
